## 🧪 Proyectos

### 🔐 Windows Hardening

Proyecto de endurecimiento de seguridad realizado sobre Windows Server 2022, basado en recomendaciones del CIS Benchmark.

Incluye configuraciones relacionadas con cuentas de usuario, políticas de contraseñas, bloqueo de cuentas, SMBv1, Windows Defender Firewall, servicios innecesarios y protección de credenciales.

➡️ [Ver proyecto](./projects/windows-hardening/)
